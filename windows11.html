Windows 11

A dedicated Windows 11 experience for Fundray — built with the same safety rules as the rest of the toolkit: restore point first, whitelist-only, fully reversible.

Windows 11 support is currently in development. Stay tuned.

We are building the Windows 11 Experience Pack — a set of safe, reversible Windows 11 tweaks. Nothing on this page is ready to download yet. When the pack ships, it will be announced here first and published on GitHub Releases.

What's planned

A first look at what the pack may include. Plans can change while development is ongoing — no dates and no promises; only tested features get announced.

  • Planned

    Modern right-click menu

    Restore the classic full context menu on Windows 11 — with a one-click switch back to the default.

  • Planned

    Taskbar alignment

    Center or left-align the taskbar, your call — applied safely through documented settings.

  • Planned

    One-click apply

    Every item individually checkable, a restore point created first, every change logged and reversible.
