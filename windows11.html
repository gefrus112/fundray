Windows 11 is a first-class target since Fundray v2.1.

Pick [8] Windows 11 tweaks in the installer menu — or run the script directly. Every change goes into the same undo log as everything else, and the script politely refuses to run on Windows 7/10 where the tweaks make no sense.

The Windows 11 tweaks

Two settings, both documented registry values, both one switch away from gone.

  • Available

    Classic right-click menu

    Bring back the full context menu instead of the condensed Windows 11 one — "Show more options" gets old fast. One registry key, one switch to revert, explorer restart applied for you.

  • Available

    Taskbar alignment

    Center or left-align the taskbar through the documented TaskbarAl setting — your call, applied safely, reversible.

PowerShell — apply the Win11 tweaks
PS> powershell -NoProfile -ExecutionPolicy Bypass ^ -File scripts\win11.ps1 -Menu -TaskbarAlign left [OK] Classic right-click menu enabled. [OK] Taskbar alignment set to: left. Restart explorer.exe to see both changes.

What runs on Windows 11

The exact module matrix — no asterisks hidden in footnotes.

Module Windows 7 SP1 Windows 10 Windows 11
Performance optimization✓✓✓
Windows Terminal profile✓✓✓
Power Panel shutdown GUI✓✓✓
Defender control (opt-in)✓✓✓
Visual-effect tuning✓✓✓
Logon background (OEMBackground)✓✓—
Classic right-click menu——✓
Taskbar alignment——✓

Why the one dash? The OEMBackground logon-background method is a Windows 7/10 mechanism; on Windows 11 Microsoft locks the logon imagery to Spotlight and it is not reliably overridable. Fundray skips the module there instead of shipping something broken.

Same safety rules

Restore point before every run, whitelist-only service edits, every registry change in the undo log, and uninstall.bat that re-enables Defender and cleans up completely. Windows 11 gets the exact same guarantees.

The BIOS splash stays honest
