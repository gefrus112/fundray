Verify before you run

Thirty seconds of checking beats an afternoon of cleanup.

:: 1. Get the published checksum from SHA256SUMS.txt in the release :: 2. Compute the checksum of your downloaded file: certutil -hashfile Fundray-v1.0.zip SHA256 :: 3. The two strings must match exactly. :: On Windows PowerShell you can also use: Get-FileHash .\Fundray-v1.0.zip -Algorithm SHA256
Why the warning? Batch files from the internet trigger SmartScreen and Mark-of-the-Web. That is expected for unsigned open-source tools. Read install.bat in Notepad, verify the checksum, then run it as administrator.

After the download

Three commands, five minutes, one restore point.

  1. Unzip

    Right-click the ZIP → Extract All… to a folder like C:\Fundray\.

  2. Run as administrator

    Right-click install.bat → Run as administrator and pick your modules from the menu.

  3. Keep the undo

    Leave uninstall.bat next to your restore points — everything Fundray changes can be rolled back.

Prefer building from source?

Clone the repository and run build.bat — csc.exe and MSBuild are already on every Windows 7 SP1 / 10 machine with .NET 4.8.
