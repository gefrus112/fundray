New in v5

Fundray Linux — now it's real

The Windows toolkit tunes the machine you have. Fundray Linux is a different thing entirely: an actual, bootable Linux distribution assembled from the official 6.12 LTS kernel — ~6 MB, zero services, live from RAM, boot-tested in QEMU with its own fundray command line.

Linux 6.12.115 LTS ~6.3 MB ISO BIOS + UEFI boot 0 services — by design GPL-2.0
fundray@ttyS0 — live ISO
fundray> uname -a Linux fundray 6.12.115-fundray #1 SMP x86_64 GNU/Linux fundray> fundray info Kernel : Linux 6.12.115-fundray (x86_64) Memory : 494 MB total · 479 MB available Services : 0 (there is no service manager — by design) Storage : initramfs in RAM — no disk is mounted or touched

Boot it in QEMU — or from a USB stick

The ISO boots BIOS (El Torito + isohybrid MBR) and UEFI alike. Try it inside a virtual machine first, or write it to a USB stick and take it anywhere — nothing is installed, nothing persists, no disk is ever touched.

  • qemu-system-x86_64 -m 512 -cdrom fundray-linux-1.0-x86_64.iso
  • fundray bench, fundray clean, fundray rebirth — a tiny CLI built in
  • Build it yourself: cd os && ./build.sh — kernel, BusyBox and ISO from source

Safety first — and honest limits

Fundray is designed so every single change can be rolled back. Equally important: it refuses to pretend it can do things it cannot.

What Fundray does

  • Restore point first — before every optimization run
  • Whitelist-only edits — critical services are never touched
  • Logged & reversible — one-click undo via revert.ps1
  • SHA256 checksums published with every release
  • No activation cracking, no licensing bypasses, ever
  • No bundled closed-source binaries

What it will never do

  • No hardware miracles — it frees friction, it cannot make an old machine new
  • No fake FPS numbers — a quieter Windows is a faster-feeling Windows; that is the whole promise
  • No compatibility breaks fixed — tuning cannot make unsupported software run
  • No firmware changes — the BIOS / American Megatrends splash is not Windows
  • No system-file patching — boot animations require replacing bootres.dll, and Fundray refuses
Questions

Asked before every install

The short versions. The full FAQ goes deeper — including Defender and the boot animation.

Is Fundray an operating system?

No — and it never claims to be. The Windows toolkit tunes the Windows installation you already have. Our separate distribution, Fundray Linux, is a real operating system — a bootable live distro built from the official Linux kernel.

Is everything really reversible?

Yes. Every change is written to an undo log in %ProgramData%\Fundray\logs, revert.ps1 replays it backwards, a restore point is created before every run, and uninstall.bat removes Fundray completely. See Revert everything.

Does it work on Windows 11?

Yes — the installer detects Windows 11 and unlocks the Win11 module: the classic full right-click menu and taskbar alignment, both documented registry settings, both in the undo log. Windows 11 support →

Will it make my old laptop new?

Honestly? No software can. Fundray removes the friction — auto-start pile-ups, noisy services, wrong power plans — so the hardware you have stops getting in its own way. A quieter Windows is a faster-feeling Windows; that is the whole promise, and there are no fake FPS numbers here.

Why does SmartScreen warn about install.bat?

The batch file is unsigned, so Windows cannot vouch for it — that is expected for open-source scripts, not a malware verdict. Verify the SHA256 checksum, read install.bat in Notepad, then choose More info → Run anyway. Details →

Requirements

Modest on purpose — Fundray targets the machines that need it most.

Operating system Windows 7 SP1, Windows 10 or Windows 11 (64-bit recommended). The installer detects your version and adjusts each module.
Framework .NET Framework 4.8 (preinstalled on Windows 10/11; free download for Windows 7 SP1)
PowerShell Windows PowerShell 2.0 or newer (5.1 recommended)
Terminal (optional) Windows Terminal, only if you want the Terminal configuration module
Rights Administrator — required for restore points, power plans and services
