Three steps between you and the new feel

No account, no setup wizard, no bundled extras. It is a folder of readable scripts.

01

Download & verify

Grab a release from GitHub and check its SHA256 with certutil -hashfile — checksums ship with every release.

02

Run install.bat

Right-click → Run as administrator. Pick a module — the installer detects Windows 7 SP1 / 10 / 11 and creates a restore point first.

03

Reboot reborn

Restart from the Power Panel. Your machine comes back with a lighter startup queue, quieter services and the right power plan.

Safety first — and honest limits

Fundray is designed so every single change can be rolled back. Equally important: it refuses to pretend it can do things it cannot.

What Fundray does

  • Restore point first — before every optimization run
  • Whitelist-only edits — critical services are never touched
  • Logged & reversible — one-click undo via revert.ps1
  • SHA256 checksums published with every release
  • No activation cracking, no licensing bypasses, ever
  • No bundled closed-source binaries

What it will never do

  • No hardware miracles — it frees friction, it cannot make an old machine new
  • No fake FPS numbers — a quieter Windows is a faster-feeling Windows; that is the whole promise
  • No compatibility breaks fixed — tuning cannot make unsupported software run
  • No firmware changes — the BIOS / American Megatrends splash is not Windows
  • No system-file patching — boot animations require replacing bootres.dll, and Fundray refuses

Requirements

Modest on purpose — Fundray targets the machines that need it most.

Operating system Windows 7 SP1, Windows 10 or Windows 11 (64-bit recommended). The installer detects your version and adjusts each module.
Framework .NET Framework 4.8 (preinstalled on Windows 10/11; free download for Windows 7 SP1)
PowerShell Windows PowerShell 2.0 or newer (5.1 recommended)
Terminal (optional) Windows Terminal, only if you want the Terminal configuration module
Rights Administrator — required for restore points, power plans and services
