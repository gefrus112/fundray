Install it from the terminal

Five commands, five minutes, one restore point. You can do every step with the mouse too — but the terminal way is faster and shows you exactly what happens.

1 · Unzip and enter the folder

Extract the release ZIP to C:\Fundray\, then open PowerShell or Command Prompt in that folder (type cmd in the Explorer address bar, or hold Shift + right-click → Open PowerShell window here):

PowerShell — download & verify
PS> cd C:\Fundray PS C:\Fundray> dir install.bat optimize.bat scripts\ docs\ ...

2 · Verify the checksum

Compare your download against SHA256SUMS.txt from the release. Thirty seconds of checking beats an afternoon of cleanup:

Command Prompt — SHA256
C:\Fundray> certutil -hashfile install.bat SHA256 SHA256 hash of install.bat: e5b007ceee341c11db154cf720e20b673a67c090a9fa714eb214ed9ab7243f6c CertUtil: -hashfile command completed successfully.

PowerShell equivalent: Get-FileHash .\install.bat -Algorithm SHA256. The hash must match SHA256SUMS.txt exactly. If it differs, do not run anything — open a GitHub issue instead.

3 · Run the installer

From the same elevated terminal, launch the menu:

Command Prompt — installer menu
C:\Fundray> install.bat Fundray installer - detected: Windows 10/11 What do you want to install? [1] Full install - performance + terminal + panel [2] Performance only [3] Windows Terminal profile [4] Appearance tweaks [5] Boot & splash (logon background) [6] Power Panel (shutdown GUI) [7] Defender control (opt-in) [8] Windows 11 tweaks (Win11 only) [9] Files only (no tweaks) Choice:

The script self-elevates if you forgot to run it as administrator. It then deploys to %ProgramFiles%\Fundray, creates Start Menu shortcuts, registers a clean Add/Remove Programs entry — and creates the restore point before touching anything.

4 · Reboot

Power-plan and service changes fully apply after a restart. Your undo log lives in %ProgramData%\Fundray\logs — keep it.

SmartScreen note: the batch file is unsigned. If Windows warns you, click More info → Run anyway — after checking the checksum, that is safe for an open-source script you can read in Notepad first.

First launch

  1. Create the baseline

    Start Fundray from the Start Menu, open the Performance tab and click Create restore point. Fundray accepts nothing less as a first move.

  2. Apply what you need

    Tick only the tweaks you want and click Apply selected optimizations. Everything is printed in the status log and written to %ProgramData%\Fundray\logs.

  3. Keep the undo close

    Run revert.ps1 from the same console — or the full uninstall.bat — and every change replays backwards. See Revert everything below.

Performance optimization

One command walks the five steps that matter on an aging machine — announced, logged, undoable:

PowerShell — run the optimizer by hand
PS> powershell -NoProfile -ExecutionPolicy Bypass -File scripts\optimize.ps1 -All 09:14:02 === Fundray performance optimization started === 09:14:02 OS: Windows 10 Pro 09:14:03 [1/5] Ensuring a system restore point exists... 09:14:09 Restore point created. 09:14:09 [3/5] Startup: 6 entries disabled (list saved).
  • High (Win 7) or Ultimate Performance (Win 10/11) power plan
  • Whitelist-only service tuning — critical services are never touched
  • Startup cleanup with a before/after list saved to disk
  • Temp files + Windows Update cache cleanup

Windows Terminal profile

Fundray adds a dedicated Fundray profile to your existing Terminal settings.json — Cascadia Code, a dark scheme, a 120×30 window. Your profiles are never overwritten and a backup of your original file is kept automatically. Works wherever Windows Terminal is installed (Windows 7 users can install it, but it is optional).

Terminal guide in the repository →

Boot & splash

Set your own logon background through the documented OEMBackground registry method (Windows 7 and 10), and get straight answers about the boot screens Fundray cannot touch — including the American Megatrends splash, which lives in your motherboard firmware. The guide walks you through BIOS Quiet Boot settings instead of pretending software can remove it.

Boot & splash guide in the repository →

Power Panel

Launch Fundray Power Panel from the Start menu. Six big buttons: Restart, Shut down, Sleep, Sign out, Lock and Restore point. Restart and Shut down confirm; the rest act immediately; the restore-point button creates a fresh checkpoint before you try anything risky.

Power Panel guide in the repository →

Defender control Opt-in

Menu item [7] exposes the opt-in switch: pause or re-enable Windows Defender real-time protection. It uses documented Group Policy keys, warns before acting, logs the change, and uninstall.bat re-enables protection automatically. If you have no other antivirus, leave Defender on — that is the safe default and Fundray's default too.

Windows 11 tweaks New

On Windows 11, installer option [8] (or the script directly) adds the two tweaks everyone asks for — both documented registry settings, both in the undo log:

PowerShell — Windows 11 tweaks
PS> powershell -NoProfile -ExecutionPolicy Bypass -File scripts\win11.ps1 -Menu -TaskbarAlign left 09:20:11 OS: Windows 11 Pro - Win11 tweaks available. 09:20:12 [OK] Classic right-click menu enabled. 09:20:12 [OK] Taskbar alignment set to: left. 09:20:12 Restart explorer.exe to see both changes.
  • Classic right-click menu — the full context menu back, one switch to revert
  • Taskbar alignment — -TaskbarAlign left or center
  • Self-checks: on Windows 7/10 the script politely refuses to run

Revert everything

Three safety layers, deepest last:

  1. Fundray's own undo log

    PowerShell — one-click revert
    PS> powershell -NoProfile -ExecutionPolicy Bypass -File scripts\revert.ps1 Reverting from 1 change log(s): changes-20261102-091402.csv [OK] Registry ... -> restored

  2. Terminal settings backup

    The original settings.json comes back byte-for-byte — the path is printed in the Terminal module's log.

  3. Windows System Restore

    The restore point Fundray created before every run. Full uninstall: uninstall.bat re-applies defaults, re-enables Defender, removes shortcuts and the Fundray folder.

SmartScreen warnings, explained

Why the warning? Batch files from the internet trigger SmartScreen and Mark-of-the-Web. That is expected for unsigned open-source tools — it means no certificate vouches for the file, not that it is malware. Verify the SHA256 checksum, read install.bat in Notepad, then choose More info → Run anyway.

Everything Fundray runs is plain text: scripts\optimize.ps1, scripts\terminal-config.ps1, scripts\appearance.ps1, scripts\win11.ps1 and scripts\revert.ps1. Read them before you run them — that is the point.
