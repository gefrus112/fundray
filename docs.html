Install in five steps

From download to a tuned system in about five minutes.

  1. Download

    Grab the latest release ZIP from the Download page — it links straight to GitHub Releases. No mirrors, no download managers.

  2. Verify the checksum

    Open PowerShell in the download folder and compare against SHA256SUMS.txt:

    Get-FileHash .\Fundray-*.zip -Algorithm SHA256

  3. Run the installer

    Unzip, then right-click install.bat → Run as administrator. The installer asks for the restore point it creates before touching anything.

    SmartScreen note: the batch file is unsigned. If Windows warns you, click More info → Run anyway — after checking the checksum, that is safe for an open-source script you can read.

  4. Pick your modules

    The installer menu runs the same scripts you could run by hand: [1] Full install · [2] Performance only · [3] Terminal only · [4] Appearance · [5] Boot & splash · [6] Power Panel · [7] Defender control. Restore point first, always.

  5. Reboot and keep the undo log

    A restart applies power-plan and service changes. Your log and one-click undo live in %ProgramData%\Fundray\ — see revert.md.

Using the Power Panel

The everyday GUI — here is the whole workflow.

Everyday use

Shut down, restart, protect

Launch Fundray Power Panel from the Start menu. Click the action you need — that is the whole interface. Restart and Shut down ask for a confirmation click; Sleep, Sign out and Lock act immediately; Restore point creates a fresh checkpoint before you try anything risky.

  • Pin it to the taskbar for one-click access
  • Runs from %ProgramFiles%\Fundray\scripts\powerpanel.ps1
  • C# build available via build.bat for purists

Uninstall

The exit is as clean as the entrance.

  • Run uninstall.bat as administrator — it re-applies defaults
  • Re-enables Windows Defender if the opt-in switch was used
  • Removes shortcuts, scheduled entries and the Fundray folder
  • Or restore a full System Restore point from Windows itself
