FAQ

Frequently asked questions

Straight answers — including the ones other tools dodge.

Is Fundray an operating system?

No — and it never claims to be. Fundray is an enhancement toolkit that installs on top of the Windows you already have (Windows 7 SP1 or Windows 10). It tunes services, power plans, Terminal, boot-time appearance and a few UX niceties. Windows stays Windows; Fundray just makes it smoother.

Can Fundray remove the American Megatrends boot screen?

Not from inside Windows — nobody honestly can. That screen is drawn by your motherboard's BIOS firmware before Windows even loads, so it belongs to your hardware, not to the operating system. What you can do legitimately: enter BIOS setup (usually Del or F2 at power-on) and look for Quiet Boot, Full Screen Logo or Boot Logo settings. Fundray's boot & splash guide walks you through it, and its software-side tweaks (logon background) cover everything Windows controls.

Will Fundray make my Windows 7 laptop run the latest games?

No, and the honest answer matters here. Tuning frees CPU, RAM and disk friction — it cannot add DirectX 12 support that Windows 7 lacks. Recent Minecraft: Java Edition releases, for example, no longer officially support Windows 7. Use the version of each game that still supports your OS; Fundray will not pretend otherwise.

Why would I disable Windows Defender, and is it safe?

The Defender switch is opt-in and exists for a narrow, common case: power users who already run another antivirus, or who pause real-time protection for a specific heavy task. It uses documented Group Policy keys, warns before acting, logs the change, and uninstall.bat re-enables protection automatically. If you have no other antivirus, leave Defender on — that is the safe default and Fundray's default too.

Is everything reversible?

Yes — that is the project's core rule. Three safety layers: (1) Fundray's own undo log and one-click restore, (2) the Terminal settings.json backup, (3) a Windows System Restore point created before any optimization. Run uninstall.bat or restore a checkpoint and you are back to where you started.

Why does SmartScreen warn about install.bat?

Because it is an unsigned batch file downloaded from the internet. That is expected and not a sign of malware — it just means no code-signing certificate vouches for the file. Verify the SHA256 checksum from the release, read the script in Notepad (it is plain text for a reason), then choose More info → Run anyway.

Does the boot animation get replaced?

No. Replacing the boot animation means patching bootres.dll, a Windows system file — the fastest way to turn a slow laptop into an unbootable one. Fundray refuses to touch system files. You get the documented logon-background tweak and a BIOS guide instead.

What about Windows 11?

A dedicated Windows 11 Experience Pack is being built on the Windows 11 page — nothing is ready to download yet, and no dates are promised. The current toolkit already runs fine on Windows 10; the pack will add Win11-specific touches like the classic right-click menu.
