# Screenshots

This folder is a **placeholder** — it fills up as soon as the first builds
land. It is intentionally empty (apart from this file) so the repository stays
honest: no mockups, no faked results.

## What will live here

| File | Content |
| --- | --- |
| `overview-tab.png` | Fundray main window, Overview tab |
| `performance-tab.png` | Performance tab with checkboxes and status log |
| `restore-point.png` | Restore point prompt / confirmation |
| `terminal-tab.png` | Terminal module: apply / restore buttons |
| `terminal-profile.png` | Windows Terminal with the Fundray profile active |
| `appearance-tab.png` | Appearance module (login background picker) |
| `before-after.png` | Optional: startup time / memory comparison |

## Contributor conventions

- PNG format, capture at 100% scale on Windows 10 or 11 (Windows 7 shots are
  welcome in a `win7/` subfolder).
- Do **not** Photoshop results, and never claim Windows 11 features in
  screenshots — the Windows 11 Experience Pack is still in development.
- Keep file sizes reasonable (< 500 KB each) so the repository stays lean.
